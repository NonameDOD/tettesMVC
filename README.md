# Tettes – MVC Java projekt

## Leírás
A program egy egyszerű logikai feladatot old meg MVC (Model–View–Controller) tervezési minta segítségével.

A program ellenőrzi, hogy a négy személy állításai között van-e egyezés.

## Projekt felépítése
- **Model:** Tárolja a változókat és végrehajtja az ellenőrzést.
- **View:** Megjeleníti az eredményt a konzolon.
- **Controller:** Összekapcsolja a Modelt és a View-t.
- **Main:** Elindítja a programot és beállítja a teszteseteket.

## Futtatás
A `main.Main` osztály futtatásával indítható a program.

## Kimenet
A program két különböző beállítással végzi el az ellenőrzést, és kiírja:
- `Meg lehet oldani!`
- `Nem lehet megoldani!`
